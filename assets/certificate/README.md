# Participation certificate

- `participation-template.pdf` is the organisers' signed design (A4 portrait). `src/certificate.js` writes each swimmer's
  name, school, event(s) and age group on its blank lines. To change the design, replace this file; if the blank lines
  move, update `LINES` in `src/certificate.js`.
- `CormorantGaramond_*.ttf` are Cormorant Garamond by Christian Thalmann (SIL Open Font License 1.1,
  https://openfontlicense.org), trimmed to Latin characters.
